# 🚀 Competitive Programming Vault

A curated repository of "Golden Problems" — the ones that challenged my intuition, required a unique observation, or taught me a high-level algorithmic pattern.

## 📂 Structure
Problems are categorized by the core technique required to solve them:
- **[Greedy](./Greedy)**: Focus on local optimality and exchange arguments.
- **[Dynamic Programming](./DP)**: State transitions, bitmasking, and optimization.
- **[Advanced Math](./Math)**: Number theory, combinatorics, and modular arithmetic.
- **[Graphs/Trees](./Graphs)**: Flows, matching, and centroid decomposition.
